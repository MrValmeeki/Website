# Atharv Babu — Portfolio

A Next.js + TypeScript portfolio redesign with Tailwind CSS, Motion, and Lucide icons.

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000).

## Update content

Personal content is isolated in:

- \`data/profile.ts\`
- \`data/projects.ts\`
- \`data/skills.ts\`
- \`data/experience.ts\`

The accent color is centralized as \`--accent\` in \`app/globals.css\`.
