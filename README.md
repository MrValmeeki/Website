# ATHARV.OS // Robotics & AI Engineering Portfolio

A high-performance, industrial cyberpunk developer portfolio and interactive laboratory built for **Atharv Babu** — Robotics & AI Engineering student focusing on game dev systems, numerical physics simulations, and low-level software.

Designed around a hardware diagnostics aesthetic with solid industrial colors, zero gradient noise, and real-time interactive subsystems.

---

## ⚡ Technical Architecture & Stack

### Core Framework & Runtime
- **[Next.js 16](https://nextjs.org/)** — React framework utilizing the App Router and Turbopack compiler for near-instantaneous page generation and builds.
- **[React 19](https://react.dev/)** — Concurrent rendering, hooks, and modern component lifecycle management.
- **[TypeScript](https://www.typescriptlang.org/)** — End-to-end static type safety across all project models, subsystem diagnostic schemas, and configuration profiles.

### Styling & Visual Design System
- **[Tailwind CSS](https://tailwindcss.com/) & Modern CSS Tokens** — Engineered with custom HSL tokens, raw `#06080d` chassis black background, and sharp cyber-accent palettes (`cyan-400`, `violet-400`, `amber-400`, `emerald-400`).
- **Strict Aesthetic Principle**: Solid, curated colors with zero gradient noise, high contrast ratios, and industrial corner-frame crosshair markers (`+`).
- **Typography**:
  - `Space Grotesk` — Display headers and high-impact structural typography.
  - `JetBrains Mono` — Monospaced telemetry labels, CLI interface, and engineering diagnostics.

### Motion, Interactivity & Accessibility
- **[Framer Motion](https://www.framer.com/motion/)** — Fluid UI spring physics, scroll-linked hairline telemetry bar, spring-animated filter pills (`layoutId`), and staggered entrance reveals.
- **Accessible Motion**: Complete integration with `useReducedMotion()`. If a visitor has reduced motion enabled in their OS, animations gracefully snap without jarring transitions.

### Procedural Web Audio (SFX Engine)
- **Web Audio API** — Custom procedural synthesizer written from scratch (`lib/sound.ts`). Generates pure algorithmic soundwaves (sine wave frequency sweeps, tactile low-latency click transients, UI blips) without loading external audio files or MP3 assets.
- **Preference Persistence**: User-controlled sound toggle persisted in `localStorage`.

### Real-Time Canvas Simulation
- **HTML5 Canvas 2D Context** — Autonomous mobile robotics kinematic simulation. Features real-time obstacle avoidance, raycasted radar scanning beams, and continuous trajectory computation rendered at 60 FPS.

## 🚀 Featured Engineering Projects

- **AshVale** — Custom 2D action RPG engine engineered from scratch in modern C++. Implements deterministic tick updates, AABB collision detection, sprite sheet animations, and modular finite state machines.
